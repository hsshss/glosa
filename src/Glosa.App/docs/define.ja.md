# define.yaml — Glosa の対象音源の定義

[English](define.md)

対象音源の一覧と、曲がどの音源向けかを判別する規則を書いたファイルです。プログラムと同じフォルダにあります（Windows と Linux では実行ファイルと同じフォルダ、macOS では `Glosa.app/Contents/MacOS` の中）。

## 定義を変えるには

`define.yaml` を直接書き換えず、上書き用のファイルを編集してください。 
設定フォルダ（**設定 → 設定フォルダを開く**）で次のようにします。

1. `define.override.yaml.sample` の名前を `define.override.yaml` に変えます。
2. `define.override.yaml` を書き換えて、Glosa を起動し直します。

- `define.override.yaml` があると、`define.yaml` の代わりにそちらを読み込みます。
- 見本は起動するたびに最新の `define.yaml` から書き出されます。新しいバージョンの変更を取り込むときは、見本と見比べてください。
- 読み込めなかったときは同梱の `define.yaml` を使い、起動したときにメッセージで理由を知らせます。

環境設定の「TMIDI定義ファイルで対象音源を判別する」を入れているときは、`patterns` と `dataDetection` は使いません。

## version

書式のバージョンです。見本のまま変えないでください。

## modules

対象音源の一覧です。この並びが、プレイリストの「対象音源」メニューなどの候補になります。
`THRU`・`GS`・`XG`・`CM-64` は Glosa が内部で使用するので、一覧から消しても自動で足されます。

| 項目 | 内容 |
|---|---|
| `name` | 音源の名前。TMIDI定義ファイルの `[tdfindex]` と同じ名前にします。 |
| `patterns` | この音源と判別する正規表現（下を参照）。 |
| `fallback` | `true` にすると、ほかの音源がどれも当たらなかったときだけ調べます。 |
| `initializeType` | 初期化の種類（下を参照）。 |

### patterns

- .NET の正規表現を、YAML の単一引用符で囲んで書きます（`'` そのものは `''`）。大文字と小文字は区別しません。
- 全角の英数字や記号は半角にそろえてから照合するので、半角で書けば十分です。
- 語に区切らずに照合します。前後に来てはいけない文字は、パターンの中に書きます。同梱のパターンは、前を `(?<![0-9A-Za-z])`、後ろを `(?![0-9A-UW-Za-uw-z])`（`Ver` などの V は許す）にしています。
- `^` と `$` は、ファイル名・タイトルなど、調べる情報それぞれの先頭と末尾に当たります。添付テキストのように行が分かれているものでは、各行の先頭と末尾にも当たります。
- 2 つのパターンが同じ文字に当たるときは、上に書いたほうが勝ちます。長い型番を先に書いてください（`8850` を `88` より前に）。

### initializeType

TMIDI定義ファイルを読み込んでいないとき、ポートマップの「出力音源」がこの音源なら、曲を始める前にそのマップの「リセット」に印を付けたポートへ送ります。環境設定の「曲の前に出力音源をリセットする」を外すと送りません。

| 値 | 送るもの |
|---|---|
| `GM` | GM System On |
| `GS` | GS Reset |
| `SC88` | GS Reset と、SC-88 以降のシステムモード設定 |
| `XG` | XG System On |
| `MT32` | 全チャンネルのコントローラのリセット |

## nameDetection

| 項目 | 内容 |
|---|---|
| `maxDocumentLength` | 添付テキストの先頭から調べる文字数。 |

## dataDetection

名前で判別できなかったとき、曲の先頭近くにある GS・XG・CM-64 の初期化メッセージで判別します。環境設定の「判別に使う情報」で「曲のデータ」を外すと使いません。

| 項目 | 内容 |
|---|---|
| `maxMessages` | 曲の先頭から調べるメッセージの数。 |

## 判別に使う情報

調べる情報とその順番、複数の機種が書かれているときにどちらを採るかは、環境設定の「対象音源の判別」で選びます。
